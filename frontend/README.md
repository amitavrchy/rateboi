# RateBoi Web (frontend)

Next.js 16 (App Router, `src/`), React 19, Tailwind CSS 4, TypeScript.
Public SEO site (Bangla-first) + seller dashboard PWA + admin + public tracking page. Rules: [`AGENTS.md`](AGENTS.md).

```bash
cp .env.example .env.local
npm install
npm run dev        # http://localhost:3010
npm run typecheck
npm run lint
npm run build
```
